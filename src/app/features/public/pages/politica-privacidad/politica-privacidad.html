1. Responsable del tratamiento

Fadex Barber es responsable del tratamiento de los datos personales que proporcionas mediante esta plataforma, formularios, reservas y canales de atención.

2. Datos que recopilamos

Podemos solicitar datos como nombre, teléfono, correo electrónico, nombre de usuario, información de reservas y datos necesarios para procesar una compra. No solicitamos información que no sea necesaria para prestar nuestros servicios.

3. Finalidades

Utilizamos tus datos para gestionar tu cuenta, confirmar reservas, procesar pedidos, atender consultas, mejorar la experiencia de uso y cumplir obligaciones legales. Solo enviaremos comunicaciones comerciales cuando corresponda y de acuerdo con tus preferencias.

4. Seguridad y conservación

Aplicamos medidas razonables de seguridad para proteger la información contra accesos, alteraciones o divulgaciones no autorizadas. Conservamos los datos durante el tiempo necesario para cumplir las finalidades informadas o las obligaciones legales aplicables.

5. Compartición de información

No vendemos tus datos personales. Solo podremos compartir la información con proveedores que nos ayudan a operar la plataforma o cuando exista una obligación legal, una orden de autoridad competente o una necesidad legítima relacionada con el servicio solicitado.

6. Tus derechos

Puedes solicitar acceso, rectificación, actualización o eliminación de tus datos, así como retirar autorizaciones cuando sea aplicable. Para ejercer estos derechos, comunícate con Fadex Barber a través de nuestros canales oficiales.

}
